# Telegram News Bot

Бот собирает новости из RSS-лент про ИИ, робототехнику, науку, программирование
и ИТ, пересказывает их по-русски через бесплатную модель на OpenRouter и
публикует в Telegram-канал. Два раза в сутки вместо обычного поста выходит
дайджест «Главное в мире за день». Сервера нет — запуск по расписанию через
внешний будильник и GitHub Actions, выполнение занимает минуты.

## Возможности

- **5 тематических категорий**, каждая с несколькими источниками: ИИ, робототехника, наука, программирование, ИТ — плюс отдельный пул мировых лент для дайджеста.
- **Перевод и суммаризация одним запросом к LLM** — модель сама решает, переводить ли (для Habr — нет, для TechCrunch — да), и сразу выдаёт заголовок, выжимку и описание для картинки.
- **LLM-отбор самой интересной статьи** из 5 кандидатов за прогон, чтобы в канал попадало не «что попалось первым», а то, что реально зацепит ИТ-аудиторию.
- **Цепочка из 4 источников картинки** — от самого достоверного к самому крайнему: картинка из RSS → `og:image` со страницы статьи → стоковое фото по теме (Pexels) → генерация по промпту (Pollinations.ai). Если все четыре не сработали, пост уходит текстом — новость не теряется.
- **Дайджест «Главное в мире за день»** в 08:00 и 20:00 по Минску — сводка из 5 тем разных областей, отобранных одной LLM из мировых лент (BBC, Guardian, Al Jazeera, CNN).
- **Round-robin по источникам** через курсор в `data/state.json` — квота прогона распределяется по кругу, а не уходит в первый попавшийся Habr.
- **Защита от дублей** по URL в `data/seen_urls.txt` — одна и та же статья не уйдёт в канал дважды даже после перезапуска.
- **Zero-server** — бот это один скрипт, состояние между прогонами коммитится обратно в git, эфемерный раннер GitHub Actions ничего не помнит сам.
- **Все API бесплатные** — без карты и подписки: OpenRouter (free-модели), Pexels (200 req/hour), Pollinations.ai (без ключа), Telegram Bot API.

## Архитектура

```
RSS (feedparser) ──► выбор кандидатов ──► LLM-отбор (selector) ──► лучшая статья
                          │                       │                       │
                          ▼                       ▼                       ▼
                    извлечение текста      полный текст со страницы    суммаризация (ai)
                    + og:image             (trafilatura)              + промпт для картинки
                          │                       │                       │
                          └───────────────┬───────┴───────────────────────┘
                                          ▼
                            цепочка из 4 источников картинки
                RSS → og:image → Pexels → Pollinations (генерация)
                                          │
                                          ▼
                          скачивание байт + отправка в Telegram
                                          │
                                          ▼
                                    пометить URL как
                                  опубликованный (data/)
```

Подробное описание каждого модуля, поток данных и failure modes — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Как работает один прогон

1. **Выбор режима.** Если текущий час UTC попадает в `DIGEST_HOURS_UTC` (5 или 17) — прогон идёт по ветке дайджеста, иначе — по обычной. См. `main.py:125`.
2. **Сбор кандидатов.** Идём по кругу всех источников из `FEEDS`, берём по одному неопубликованному `entry` с каждого, пока не наберём `CANDIDATES_PER_RUN` штук или не пройдём весь круг. `main.py:161-172`.
3. **LLM-выбор лучшего.** Собранные кандидаты (заголовок + сниппет) перемешиваются и одним запросом к модели выбирается самый интересный для ИТ-аудитории. `selector.py:37`.
4. **Извлечение полного текста** страницы выбранной статьи через `trafilatura` и парсинг `og:image` из того же HTML — без второго сетевого запроса. `extractor.py:26`.
5. **Суммаризация.** Один запрос к OpenRouter возвращает русский заголовок, выжимку (3-5 предложений), описание для картинки на английском. `ai.py:75`.
6. **Картинка.** Пробуем кандидатов по цепочке RSS → og:image → Pexels → Pollinations, скачиваем первого успешного и отдаём байты в Telegram (не ссылку — иначе Telegram срежет пост на медленных сервисах). `main.py:49-55`, `images.py:43`, `publisher.py:74`.
7. **Публикация + пометка.** Только после подтверждённой отправки (`ok: true` от Telegram) URL добавляется в `data/seen_urls.txt`. `main.py:69-72`, `publisher.py:12`.

Если LLM-выбор не сработал (модель не вернула номер, вышла за диапазон) — фолбэк на обычный round-robin: обходим все источники и публикуем первую проходящую через пайплайн статью. `main.py:204-220`.

## Локальный запуск (для отладки)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и вписать реальные значения
python main.py
```

Один прогон завершается за минуту-две, дальше процесс просто выходит. Для
полноценной работы нужен следующий раздел.

## Деплой на GitHub Actions

### 1. Telegram-бот

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. Добавьте бота администратором в канал, куда он будет постить.
3. `CHANNEL_ID` — это `@username_канала` (для публичных) или числовой ID вида `-100xxxxxxxxxx` (для приватных — его можно узнать через [@userinfobot](https://t.me/userinfobot) или переслав сообщение из канала боту вроде @JsonDumpBot).

### 2. OpenRouter (бесплатный ИИ)

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) — только email, карта не нужна для бесплатных моделей.
2. Создайте API-ключ (`OPENROUTER_API_KEY`).
3. Без пополнения баланса действует ограниченная дневная квота запросов (см. свой dashboard на сайте) — под неё настроены `MAX_ARTICLES_PER_RUN` и `MAX_ARTICLES_PER_FEED` в `config.py`.
4. Список бесплатных моделей (`OPENROUTER_MODEL` в `config.py`) периодически меняется — актуальный: <https://openrouter.ai/models?max_price=0>.

### 3. Pexels (бесплатные стоковые фото)

1. Зарегистрируйтесь на [pexels.com/api](https://www.pexels.com/api/) — только email, карта не нужна, ключ выдаётся сразу без модерации.
2. Получите API-ключ (`PEXELS_API_KEY`).

### 4. Секреты и права в GitHub

1. Запушьте репозиторий на GitHub.
2. В **Settings → Secrets and variables → Actions** добавьте четыре секрета: `BOT_TOKEN`, `CHANNEL_ID`, `OPENROUTER_API_KEY`, `PEXELS_API_KEY`.
3. В **Settings → Actions → General → Workflow permissions** включите **«Read and write permissions»** — воркфлоу коммитит `data/` обратно в репозиторий.

### 5. Внешний будильник (cron-job.org)

GitHub Actions не гарантирует исполнение встроенного `schedule` и на практике
отбрасывает большую часть ежечасных слотов. Вместо этого репозиторий
использует `workflow_dispatch` + внешний будильник:

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (бесплатно, без карты).
2. Создайте задачу, которая раз в час дёргает API GitHub:

   ```
   POST https://api.github.com/repos/<owner>/<repo>/actions/workflows/post_news.yml/dispatches
   Authorization: Bearer <GH_TOKEN>
   Accept: application/vnd.github+json
   Content-Type: application/json

   {"ref": "main"}
   ```

3. Для приватного репозитория нужен [Personal Access Token](https://github.com/settings/tokens?type=beta) с правом **Actions: Read and write** на этот репо (fine-grained PAT) или классический `repo` + `workflow` (classic PAT). Для публичного — достаточно самого репо.
4. Поле **«Send as POST request»** в cron-job.org должно быть включено, **Request headers** — заполнены как выше (две строки `Authorization` и `Content-Type`).
5. Расписание в cron-job.org: `0 * * * *` (каждый час). main.py сам определяет по `DIGEST_HOURS_UTC`, какой прогон — дайджестовый, остальные 14 — обычные.

Если хочется просто проверить вручную: **Actions → Post news → Run workflow**.

## Конфигурация

### Переменные окружения (`.env`)

| Переменная | Описание |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather. |
| `CHANNEL_ID` | `@username_канала` или `-100xxxxxxxxxx` для приватного. |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter. |
| `PEXELS_API_KEY` | API-ключ Pexels. |

### Что крутить в `config.py`

| Константа | Смысл | По умолчанию |
| --- | --- | --- |
| `OPENROUTER_MODEL` | ID бесплатной модели. Меняется, если текущая протухла или упёрлась в квоту. | `nvidia/nemotron-3-super-120b-a12b:free` |
| `MAX_ARTICLES_PER_RUN` | Сколько постов за один прогон. Делится между обычными и дайджестами. | `1` |
| `MAX_ARTICLES_PER_FEED` | Сколько записей забирать с одной ленты. | `2` |
| `CANDIDATES_PER_RUN` | Сколько кандидатов собирать для LLM-отбора. | `5` |
| `DIGEST_HOURS_UTC` | Часы UTC, в которые выходит дайджест вместо обычного поста. | `(5, 17)` |
| `DIGEST_TOPICS` | Сколько тем в дайджесте. | `5` |
| `DIGEST_MIN_TOPICS` | Минимум тем; меньше — фолбэк на обычный пост, чтобы не уходил обрубок. | `3` |
| `MAX_IMAGE_BYTES` | Потолок скачиваемой картинки. Равен лимиту Telegram sendPhoto. | `10 МБ` |
| `FEEDS` | Словарь категория → список `(имя, URL)` RSS-лент. | см. `config.py:76` |
| `WORLD_FEEDS` | Список мировых лент для дайджеста. | см. `config.py:63` |

## Как добавить новый источник

Обычный источник — просто кортеж в нужной категории `FEEDS` (`config.py:76-109`).
Round-robin и селектор подхватят автоматически:

```python
'Программирование': [
    ('Habr: Программирование', 'https://habr.com/ru/rss/hubs/programming/articles/all/?fl=ru'),
    ('Новый источник',         'https://example.com/feed.xml'),  # ← добавили
    ...
],
```

Если нужна новая категория — добавьте ключ в `FEEDS`, тогда же она появится в
хэштегах постов. Категория-локация для дайджестов жёстко зашита в `digest.py:134`
как `'Мир'`, отдельной константы под неё нет.

## Стоимость и лимиты

| Сервис | Бесплатный лимит | Где проверить |
| --- | --- | --- |
| OpenRouter | ~50 запросов/сутки для free-моделей (зависит от модели) | [dashboard](https://openrouter.ai/settings/keys) |
| Pexels | 200 запросов/час, 20 000/месяц на ключ | [документация](https://www.pexels.com/api/documentation/) |
| Pollinations.ai | Без ключа и без явной квоты (rate-limit неофициальный) | — |
| Telegram Bot API | Без лимитов на отправку в канал | [документация](https://core.telegram.org/bots/api) |
| GitHub Actions | 2 000 минут/месяц на free-аккаунте | [billing](https://github.com/settings/billing) |

Расчёт на 16 прогонов/сутки × 1 пост = ~30 запросов к OpenRouter (16 селектов +
16 суммаризаций + 2 сборки дайджеста). Укладывается в квоту с запасом. Если
упёрлись — снизьте `MAX_ARTICLES_PER_RUN` или уменьшите количество часов в
расписании cron-job.org.

## Troubleshooting

**OpenRouter отдаёт 429.**
Исчерпана дневная квота. Либо подождите до следующего дня, либо смените
`OPENROUTER_MODEL` на другую free-модель с <https://openrouter.ai/models?max_price=0>.
`retry.py:6` уже делает 3 ретрая с экспоненциальной паузой на 429.

**Модель недоступна или сменилась.**
`free`-модели OpenRouter «протухают» без предупреждения. Меняется в `config.py:13`.
Перед сменой проверьте модель вживую через playground на сайте.

**Pollinations отдаёт таймаут / мусор.**
Генерация картинки занимает до минуты. `publisher.py:96` уже умеет откатываться
на текст без фото, если Telegram не принял изображение — пост уйдёт, новость
не потеряется.

**`og:image` битый / 404.**
Цепочка в `main.py:49-54` идёт дальше автоматически: og:image → Pexels →
Pollinations. Никаких действий не нужно.

**Конфликт `data/state.json` при ручном запуске поверх cron.**
Воркфлоу `.github/workflows/post_news.yml:26-28` уже группирует прогоны через
`concurrency.group: post-news` — одновременных запусков быть не может.

**Воркфлоу не запускается по расписанию.**
Проверьте, что cron-job.org действительно шлёт запросы (вкладка **«Executions»**
на cron-job.org). Если там пусто — задача не активна или заголовки неверные.
Проверьте также **Actions → Post news** в GitHub — последние запуски видны там.

**В канале мусор от LLM (повторяющиеся `<unk>`, обрезанные фразы).**
`ai.py:116-123` уже отбраковывает ответы, не попадающие в ожидаемый regex, — пост
не должен уйти. Если всё же проскочило — смените модель и пришлите пример
через issue, посмотрим парсинг.

## Roadmap

- **Тесты.** Сейчас нет ни unit, ни интеграционных. Покрыть хотя бы парсинг ответа LLM, цепочку картинки и атомарность записи `state.json`.
- **Метрики и алёрты.** Сейчас единственный способ узнать о проблеме — зайти в логи воркфлоу. Хочется видеть «пост не ушёл» сразу.
- **Запасной провайдер LLM.** Сейчас вся ставка на OpenRouter free-tier. При исчерпании квоты или смене модельного пула — проваливаемся, фолбэка нет.
- **Rate-limit per-feed.** Сейчас источник, который отдаёт 100 записей в час, теоретически может занять весь бюджет. Добавить лимит на загрузку с одного домена.
- **Per-source хэштеги вместо одной категории.** Сейчас тег = категория («ИИ», «Наука»). Это шумно для больших категорий вроде «ИТ».
